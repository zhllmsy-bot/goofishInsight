# 分析路径

## 1. 分析目标

这个项目的分析目标不是还原真实成交全貌，而是围绕公开列表样本建立一套可执行的买方判断视角。

第一阶段的业务目标更具体：

- 找到佳明手表里更值得立即关注的商品。
- 找到苹果 M 芯片电脑里更值得立即关注的商品。
- 用数据回答“合理价是多少”“风险在哪里”“该不该现在看”。

## 2. 分析分层

### 2.1 数据质量层

- 样本量
- 去重率
- 字段完整率
- 采集成功率
- 品类覆盖率

### 2.2 市场形态层

- 品类商品数量
- 品牌和型号分布
- 价格带分布
- 地区分布
- 新旧程度和标签分布

### 2.3 卖家结构层

- 卖家数量
- 高活跃卖家占比
- 重复发品卖家识别
- 个人闲置与店铺型卖家差异

### 2.4 时间变化层

- 新发商品数量变化
- 价格中位数变化
- 热门关键词变化
- 核心品牌/型号的样本变化

### 2.5 异常识别层

- 价格明显偏离同类中位数的商品
- 重复文案或重复图样商品
- 高频刷新或大量发品卖家

### 2.6 买方决策层

- `fair_price`
- `buy_ceiling`
- `discount_rate`
- `risk_score`
- `opportunity_score`

## 4. 可落地的分析专题

- 某品类当前的价格带结构
- 某品牌在该品类中的占比
- 同一型号的价格区间和异常值
- 高频卖家与普通卖家的差异
- 某时间窗口内上新密度变化
- Garmin 不同系列的合理价与折价机会比较
- Apple 不同 M 芯片代际和配置组合的买入机会比较

## 5. 建模路径

第一期不做复杂机器学习，先做规则驱动和统计建模：

1. 标题分词和关键词提取
2. 品牌、型号、容量、成色等字段抽取
3. 基于同类样本建立价格基线
4. 基于规则识别疑似异常商品
5. 形成可解释的风险标签
6. 形成折价与风险组合的机会评分模型

机会评分可先用代理指标近似：

- 当前挂牌价与同型号基线价的价差
- 同规格样本的价格收敛程度
- 高配置版本的溢价空间
- 成色与价格不匹配的异常低价机会
- 卖家和文本层面的风险信号

第二期再考虑：

- 文本聚类
- 相似商品归组
- 价格预测区间
- 消失时间代理模型

## 6. 数据产物

- 原始响应表
- 标准化商品表
- 商品快照表
- 卖家聚合表
- 日级指标表
- 专题分析结果表

## 7. 分析限制

- 列表数据不等于成交数据。
- 商品下架不一定等于成交。
- 卖家公开信息不代表真实身份。
- 样本可能受关键词、地区、排序和页面推荐机制影响。
- “最值得买”和“最值得提醒”在第一阶段仍然只能基于样本代理指标估算，不能当作平台真实成交口径。
